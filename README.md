# Keylogger for Flipper Zero Bad USB
This program is intended to record keystrokes on a computer, which it later stores in a file of your choice in order to load onto a flipper zero for Bad Usb attacks. It records delays as well as key inputs.

## Usage
First of all install the required libraries with `pip install -r requirements.txt`<br>
Then you need to run the script with `python main.py`<br>
It will prompt you to enter a name for the script and after entering a name and pressing enter it will start recording. It will not stop recording until you press escape. You find the created files in the folder named `/out`
